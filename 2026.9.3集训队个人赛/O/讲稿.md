## 第 1 页 · 封面

大家好！今天分享个人赛 O 题 Xor Triangle，也叫"异或三角形"。这道题代码只有二十行，核心是一条公式：
4^N 减 3^(N+1) 加 3 乘 2^N 再减 1。听上去像背答案，其实背后是两条很漂亮的异或不等式加一个标准容斥。
我会把每一步"为什么这么想"讲清楚，最后再聊两个容易翻车的细节。

## 第 2 页 · 题意

先读题：给定 N，统计满足 1 ≤ a,b < 2^N 的有序整数对 (a,b) 有多少个，使得 a、b、a 异或 b 这三个数能构成非退化三角形，
答案对 998244353 取模。注意三点：整数对是有序的，(a,b) 和 (b,a) 算两个；N 可以到 10 的 18 次方，
所以枚举 4^N 对不可能，按位 DP 也至少 O(N)，必须推闭式公式；
另外条件完全由 a、b 的二进制位决定，说明这本质上是一道位运算计数题，不是几何题。

## 第 3 页 · 关键观察：两条异或不等式

先建立整个解法的地基：两条异或不等式。记 c = a 异或 b。
第一条是上界：c 不超过 a+b。因为 a+b 等于 a 异或 b 再加上 2 倍的 a 按位与 b，所以取等当且仅当 a 按位与 b 等于 0。
第二条是下界：c 不小于 |a−b|。不妨设 a 大于等于 b，c 减去 a−b 等于 2(b − a&b)，非负；
取等当且仅当 b 等于 a&b，也就是 b 的每个 1 位都在 a 里，记作"b 按位包含于 a"。
两条合起来的推论：三角形不等式——两边之和大于第三边、两边之差小于第三边——只会在取等的地方失败，
所以退化当且仅当某条边恰好等于另外两条边之和。

（板书建议：把 a + b = a⊕b + 2(a&b) 写出来，整页推导都围绕它。）

## 第 4 页 · 转化：退化 ⟺ 三个条件之一

把上一页的三个"取等"翻译成三种退化形式：
c = a+b 等价于 a&b = 0；b = a+c 等价于 a 按位包含于 b；a = b+c 等价于 b 按位包含于 a。
所以非退化当且仅当三个条件同时不成立：a&b 非零，并且 a、b 按位互不包含。
到这里，"三角形"彻底消失了，问题变成三个纯位运算条件的计数。

## 第 5 页 · 容斥框架

接下来的动作非常标准：容斥。三个坏条件对应三个坏事件 E1、E2、E3。
全体对数有 (2^N − 1) 的平方个，答案是总数减去坏事件并集的大小。下面逐个计算每一项。

## 第 6 页 · 计数 ①：|E₁|

先算 E1：a&b 等于 0，也就是两个数的 1 位完全不重叠。
看低 N 位，每一位有三种去向：只在 a、只在 b、都不在，所以有 3^N 种分配；
但要挖掉 a 等于 0 的 2^N 种和 b 等于 0 的 2^N 种——注意 a = b = 0 被挖了两次，要加回 1 种。
得到 |E1| = 3^N − 2^(N+1) + 1。

## 第 7 页 · 计数 ②：|E₂| = |E₃|

再算 E2：a 按位包含于 b。逐位看，(a_i, b_i) 只有三种合法状态：00、01、11，也是 3^N 种；
挖掉 a=0 的 2^N 种。这里有个细节：a=0 的 2^N 种里已经包含了 b=0，不用像 E1 那样再加回。
所以 |E2| = 3^N − 2^N，和 |E1| 不一样——这是这道题最容易翻车的地方：
两个集合从字面上看几乎对称，但"挖 0"的时候一个有交集、一个没有，计数结果天生不同。E3 与 E2 对称，相等。

## 第 8 页 · 交集与并集

再看交集。E1 交 E2 是空集：a&b 为 0 又要求 a 包含于 b，只能推出 a = 0，矛盾；
E1 交 E3 和三元交同理。E2 交 E3 是 a = b，共 2^N − 1 对。
把各项代进容斥公式，并集大小化简成 3^(N+1) − 5·2^N + 2。

## 第 9 页 · 最终公式与样例

总对数 (2^N − 1) 的平方展开是 4^N − 2^(N+1) + 1，减去并集，得到最终答案
4^N − 3^(N+1) + 3·2^N − 1。用官方样例核对：N=2 答案是 0；N=5 是 390——
比如 (13,24)，13 异或 24 等于 21，13+24 大于 21、13+21 大于 24、21+24 大于 13，确实构成三角形；
N=10000 是 851087540。全部吻合。

## 第 10 页 · 代码实现

代码二十行：快速幂分别算 2^N、3^(N+1)、4^N 三个幂次，然后套公式输出。
三个细节：一是三次快速幂，复杂度 O(log N)，10 的 18 次方也没压力；
二是减法先加 MOD 再取模，防止 C++ 里负数取模得到负数；
三是乘法不会爆：998244353 的平方大约是 9.96 乘 10 的 17 次方，小于 long long 上限 9.2 乘 10 的 18 次方。

## 第 11 页 · 复杂度与更多观察

复杂度：时间 O(log N)、空间 O(1)。
为什么只能推公式：枚举是 4^N 对，按位 DP 至少 O(N)，对 10 的 18 次方都不行；
而答案只与 N 有关，暗示闭式公式存在。
最后送一个彩蛋：合法三角形一定三边互异——a 等于 b 会推出 c 等于 0，a 等于 c 会推出 b 等于 0，
所以 N 等于 1、2 时答案是 0 并不奇怪。

## 第 12 页 · 总结

总结一下套路链：先用两条异或不等式把"三角形"翻译成三个位运算条件，
再定义三个坏事件做标准容斥，逐项计数得到闭式公式，最后快速幂求值。
三个可迁移的点：第一，遇到"异或 + 大小比较"，先想到 a+b = a⊕b + 2(a&b) 这个恒等式；
第二，容斥计数时每个集合单独算，"挖 0"的细节会让表面对称的集合大小不同；
第三，取模技巧——负数先加 MOD，模数平方小于 2 的 63 次方可以放心乘。
谢谢大家，欢迎提问。

### 可能的提问 & 应对

- **"|E₂| 为什么和 |E₁| 不一样？它们看上去完全对称。"**
  表面对称、细节不对称。挖 a=0 时：E₁ 里"a=0"与"b=0"有交集（a=b=0），被挖了两次要加回 1；
  E₂ 里 a=0 的 2^N 种已经包含了 b=0 这一种，不用再加回。所以 |E₁| = 3^N − 2^(N+1) + 1，|E₂| = 3^N − 2^N。

- **"a⊕b ≥ |a−b| 为什么恒成立？"**
  设 a ≥ b：a⊕b − (a−b) = a + b − 2(a&b) − a + b = 2(b − a&b) ≥ 0，因为 a&b ≤ b 恒成立。
  取等当且仅当 b = a&b，即 b 的每个 1 位都在 a 里（按位包含）。

- **"会不会出现 a⊕b > a+b，直接不满足三角不等式？"**
  不会。a⊕b = a+b − 2(a&b) ≤ a+b，上界恒成立；只有"取等"（退化）才失败。

- **"如果题面把上界写成 ≤ 2^N（而不是 < 2^N），答案会变吗？"**
  不会。含 2^N 的 (a,b) 全部是坏对：若 a = 2^N、b < 2^N，则 a&b = 0（坏）；
  若 a = b = 2^N，则 a ⊆ b 且 b ⊆ a（坏）。所以 [1, 2^N] 与 [1, 2^N) 两种题面推出同一个公式。
  （QOJ 原题写的是 < 2^N，如果现场版本写 ≤ 2^N 不必紧张。）

- **"N = 1 为什么答案是 0？"**
  a、b 只能取 1，a = b 时 c = 0，构不成三角形；且只有这一种取值。

- **"能不能用 3 进制 DP / 枚举统计？"**
  能推导出同样的计数（每个 bit 三种状态就是 3^N 的来源），但 N 到 10^18，任何 O(N) 的 DP 都超时，
  必须把 3^N 直接用快速幂算——这正是"先推公式再快速幂"的题。
